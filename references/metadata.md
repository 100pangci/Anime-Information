# 作品识别与元数据

元数据源用于辅助识别，不替代文件证据，也不是本项目的当前集成依赖。可按需查询 Bangumi、AniDB、AniList、TMDB 等公开来源；不要为了扫描而默认联网。

## 识别证据

综合使用：

1. 原始文件名中的标题、季/篇章、集数、发布组。
2. 父目录与同一批文件的命名模式。
3. 季数、集数范围、发布日期或作品年份等可验证线索。
4. 需要区分不同编码/压制时的媒体信息；内容 Hash 仅在判断字节完全相同时使用。
5. 公开元数据中的原名、别名、年份、集数和关系信息。

## 查询原则

- 只在名称/系列关系有实际歧义且查询能帮助解决时联网；尊重用户不联网或指定数据源的偏好。
- 不向外部服务上传媒体文件或私人目录结构。通常只需查询标题、年份等最少信息。
- 记录来源、候选作品标识/页面以及匹配证据；不同站点的季、OVA、电影和总集篇计数可能不同。
- 同名作品、remake、续作、第二季、Part 2、cour 和 WEB 特别篇不能只按标题匹配。
- 多来源结果冲突或仍有多个候选时，列出候选并标记 `Needs Review`，请用户确认。
- 本项目不维护元数据数据库、不自动抓取海报，也不把第三方字段写回媒体文件。

## 版本与重复

WebRip、BluRay、BDRip、不同字幕组、v2、不同语言音轨或不同字幕轨可能是用户有意收藏的版本。相同作品/集数不代表重复。应用任何版本筛选前，明确展示版本信息并由用户选择保留全部、偏好版本、分目录或其他策略。
