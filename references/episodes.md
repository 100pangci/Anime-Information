# 集数与内容类型

不同字幕组和来源的编号并不一致。集数标签要结合标题、目录、同系列文件和媒体内容判断，不能只按数字排序。

## 常见写法

| 写法 | 解释与处理 |
| --- | --- |
| `01`、`EP01`、`Episode 01` | 常见正片集数；确认季信息后才转成 `SxxExx`。 |
| `01v2`、`01 v2` | 第 1 集的修订版/重发版本，不是第 12 集，也不自动替代旧版。版本是否并存由用户决定。 |
| `12.5`、`12½` | 分数集或插入集；不要四舍五入到 12 或 13。 |
| `00`、`Episode 0` | 可能是序章、总集篇、特别篇或正片编号；根据上下文确认角色。 |
| `SP01`、`Special 01` | 特别篇；不要在没有系列规则证据时当普通第 1 集。 |
| `OVA`、`OAD` | OVA/OAD 内容；带编号时保留其编号，默认归入 Extras 或用户指定位置。 |
| `Movie`、`劇場版` | 剧场版/电影，不作为普通 TV 集。 |
| `NCOP01`、`NCED01` | 无字幕片头/片尾版本；属于 Extra。数字通常区分多个 OP/ED，不是正片集数。 |
| `PV`、`CM`、`Menu` | 预告、广告、菜单等附属内容，不当作正片集数。 |

## 识别与规范化

- 有明确季号时保留季和集数；没有证据时季号未知，不要默认填成第一季。
- `01v2` 应保留版本语义，如作为单独版本存放，或按用户指定命名为 `SxxE01v2`；不要覆盖 `SxxE01`。
- 分数集可用 `SxxE12.5` 等无损形式，或遵循现有目录规则。
- `SP01`、OVA/OAD、电影及制作特典分别保留类型与序号；不能仅因名称里出现数字就转成 `SxxExx`。
- 解析器可能把标题中的数字误判为集数，也可能漏掉组名/特别篇。核对同目录命名模式和集数范围；矛盾时标记 `Needs Review`。
- 集数缺口只作为观察结果，不证明文件缺失；不要据此联网下载或生成占位文件。
