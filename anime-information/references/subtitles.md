# 外挂字幕

外挂字幕是与媒体文件关联的独立资源。任何视频改名/移动都必须同步处理已配对字幕，并在应用后核验配对仍成立。

## 常见名称与语言

```text
Anime 01.mkv
Anime 01.ass
Anime 01.chs.ass
Anime 01.cht.ass
Anime 01.sc.ass
Anime 01.tc.ass
Anime 01.zh-Hans.ass
Anime 01.zh-Hant.ass
```

常见缩写可作为线索：`CHS` / `SC` / `GB` / `简` 常指简体中文（`zh-Hans`）；`CHT` / `TC` / `BIG5` / `繁` 常指繁体中文（`zh-Hant`）；`JPN` / `JP` 常指日文；`EN` 常指英文。不同发布组可能另有约定，未知或冲突标签不要强行规范化。

常见双语标签可包含多种语言，例如 `简日`、`繁日`、`CHS&JPN`、`CHT&JPN`、`JPSC`、`JPTC`、`CHS_JP`。扫描器会保留 `raw_language_tag` 并提供 `language_tags` 线索；双语标签的具体含义可能因字幕组而异，Agent 应保留原标签并结合目录/字幕内容判断，不要把它压缩成单一语言。

支持识别 `.ass`、`.ssa`、`.srt`、`.vtt`、`.sub` 等字幕扩展名。`.sub` 可能依赖同名 `.idx`，作为成对资源处理；不确定格式时用 `file` 或媒体工具检查。

## 配对顺序

1. 同一目录中，去掉**末尾语言标签**后的基名一致（忽略扩展名大小写差异）。
2. 作品名、集数/特别篇编号一致。
3. 发布组、来源和版本（包括 `v2`）一致或有明确兼容证据。
4. 必要时检查字幕文件内容/时间轴或媒体内封字幕轨；只靠一条线索不足时标记待审核。

不要把字幕语言标记误认为集数或发布组。`GB`、`BIG5` 也可能描述字符编码而非字幕语言，以上转换只是检索提示。不要将一条字幕自动匹配到同集的所有不同压制版本；有些版本的时间轴或剪辑长度不同。`01v2` 字幕也不能默认用于 `01`。

## 重命名与孤立项

- 若确认视频改名，已配对字幕必须同步改名、同目录移动，并保留语言与格式，例如：

  ```text
  [Group] Anime - 01.mkv       → S01E01.mkv
  [Group] Anime - 01.chs.ass   → S01E01.zh-Hans.ass
  ```

- 每一个外挂字幕都要列入计划，不能只列视频。扩展名和多段语言后缀必须完整保留。
- 同基名多语言字幕可一对多配同一视频；多个视频候选、多个同语言字幕候选或时间轴不明时，不自动选择。
- 孤立字幕、未知语言字幕、字幕字体依赖缺失、`idx/sub` 组件缺失均保留并列为 `Needs Review`；不得删除。
- 改名后检查字幕文件与视频同目录、集数相符、语言标签未丢失；若字幕含 `Fonts/` 附件依赖，字体一并按用户确认的方案归档。
