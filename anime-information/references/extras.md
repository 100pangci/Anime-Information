# 特典与附属资源

附属资源不是普通 TV Episode。根据文件名、目录、媒体内容和上下文分类；不要仅凭扩展名或一个数字推断内容。

## 常见类型

| 标记/资源 | 常见含义 | 建议角色 |
| --- | --- | --- |
| `NCOP`、`NCED` | 无字幕 OP/ED，可能有多个编号 | `Extras/` |
| `PV`、`CM`、`Trailer` | 宣传片、广告、预告 | `Extras/` |
| `SP`、`Special` | 特别篇/附加节目；有时实际属于主线 | 先判定后归档，编号不要改成普通 EP |
| `OVA`、`OAD` | OVA/OAD | `Extras/` 或系列独立子目录 |
| `Movie`、`劇場版` | 剧场版 | 独立作品/电影目录，依用户规则 |
| `OST`、`CD`、`Soundtrack` | 原声、歌曲、光盘音轨 | 音频/`Extras/` |
| `Scans`、`Booklet`、`Jacket` | 扫图、封面、歌词册 | `Scans/` 或保留原目录 |
| `Fonts`、`.ttf`、`.otf` | 字幕组字体附件 | `Fonts/`，保留附件关系 |
| `Menu`、`Interview`、`Bonus` | 菜单、访谈、花絮等 | `Extras/` |

## 归类注意

- `SP` 有时是剧情正篇、总集篇或广播特典；结合官方编号、目录和同系列文件判断。
- `00` 不必然是 Extra；可能是序章、正片、总集篇或发行盘编号。
- 镜像里的菜单、字幕、字体和章节信息可能与主视频绑定。检查附件或目录结构后再归档，勿拆散依赖资源。
- 压缩包可能包含字幕组说明、字体、字幕或扫图。扫描文件名/目录结构即可先分类；除非用户要求且解压位置明确，不自动解包。
- 光盘镜像（ISO 等）先作为镜像保留，不自动挂载、拆分或转换。
- 单独的 `.bin` 扩展名含义不确定（可能是光盘数据，也可能是普通二进制文件）；没有 `.cue` 或目录上下文等证据时保留为未知项，不仅凭扩展名归档。
- 图片不必然是 Scans；可能是封面、字幕组图、壁纸或临时文件。无法判断时设为 `Unknown`。
- 字体不应随意丢弃：ASS 字幕可能依赖特定字体。孤立字体保留并列出，不默认删除。
